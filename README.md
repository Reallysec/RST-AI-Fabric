# RST AI Fabric

Self-hosted LLM gateway: OpenAI- and Anthropic-compatible API in front of vLLM and cloud models, with per-project keys, quotas, usage reports, GPU monitoring and an audit trail. Offline install and licensing, signed one-click upgrades.

This repository hosts the public downloads and documentation for RST AI Fabric.
Releases, install instructions and the licence will be published here.
