# Security Policy

Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests. Email [security@reallysec.com](mailto:security@reallysec.com)
with the affected version, steps to reproduce, and the impact you observed.

请不要通过公开的 Issue、讨论或 PR 报告安全漏洞，请发邮件到
[security@reallysec.com](mailto:security@reallysec.com)，并附上受影响的版本、复现步骤和影响。
